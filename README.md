SauceDemo — Manual Testing



###### О проекте



Учебный проект по ручному тестированию веб-приложения SauceDemo. Цель проекта — освоить базовые практики Manual QA и сформировать портфолио с тестовой документацией и результатами тестирования.



###### Объект тестирования



Веб-приложение SauceDemo — демонстрационный интернет-магазин.



###### Объём тестирования



В рамках проекта рассматриваются следующие функциональные области:



Авторизация пользователя.



Каталог товаров и сортировка.



Добавление и удаление товаров в корзине.



Оформление заказа.



Проверка отображения данных заказа в PDF-файле.



###### Тестовое окружение



ОС: Windows 11 25H2.



Браузер: Yandex Browser 26.8.0.0.



Тестовая среда: SauceDemo.



###### Тестовая документация



Чек-лист — проверки основных функций приложения.



Баг-репорты — обнаруженные и задокументированные проблемы.



Результаты тестирования — результаты выполненных проверок.



Документация по окружению — сведения о тестовой среде.
